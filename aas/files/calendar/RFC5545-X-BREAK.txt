X-BREAK - iCalendar extension property (RFC 5545, section 3.8.8.2 "Non-Standard Properties")
Production calendar of LINE01, VF Pneumatics GmbH, Plant 01 (IDTA 02067 Production Calendar)

Purpose:     Marks a VEVENT as a break in which the asset is not planned to produce.
Value type:  BOOLEAN (TRUE / FALSE); default FALSE if the property is absent.
Used in:     VEVENT (recurring collective breaks, 10:00-10:30 and 18:00-18:30, Mon-Fri).
Example:     X-BREAK:TRUE

Interpretation:
- A break occurrence is subtracted from overlapping production slots (X-PRODUCTION-DAY:TRUE).
- During a break the line is brought into the PackML state Held by the MES and resumed (Unhold) afterwards;
  the break time counts as planned down time, not as unit down time (ISO 22400-2).
- CATEGORIES:BREAK is set in addition for clients that ignore non-standard properties.
